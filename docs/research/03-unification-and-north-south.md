# 3번 묶음 조사 양식: 삼국 통일과 남북국 (600 ~ 935)

> 이 파일을 채워서 넘겨주시면 `data/`의 YAML·GeoJSON으로 옮깁니다. 작성 규칙은 [DATA_GUIDE.md](../DATA_GUIDE.md)를 참고하세요.
>
> - 아래의 나라·국경 변화 시점·사건 목록은 **조사할 후보**입니다. 사실 여부와 연도는 조사하며 확인하고, 빼거나 더해도 됩니다.
> - 요약은 **직접 쓴 문장**으로 적어 주세요 (데이터가 CC BY-NC-SA로 공개됩니다).
> - 연도는 평소처럼 적으면 됩니다 (기원전은 "기원전 57"). 내부 표기로는 제가 바꿉니다.
> - 이 구간에는 지금 **기능 확인용 샘플 데이터**가 들어 있습니다. 조사 결과로 모두 교체합니다.

## 범위

- **기간**: 600년 ~ 935년 (신라 멸망)
- **4번 묶음(고려)과 겹치는 부분**: 후삼국(900~936)과 고려 건국(918)은 이 묶음에서 조사합니다. 고려의 나라 정보도 여기서 한 번 작성하고, 936년 이후는 4번 묶음에서 이어 갑니다.
- **2번 묶음(삼국 성립)과의 경계**: 고구려·백제·신라의 건국 이후 600년까지는 2번 묶음에서 조사합니다. 세 나라의 나라 정보(존속 기간, 수록 근거)는 **이 묶음에서 먼저 작성**합니다.

## 2. 국경 변화 시점

국경은 **바뀔 때만** 새로 적습니다. 다음 변화 전까지 같은 국경이 유지됩니다.

```
### (연도) (무엇이 바뀌었나)
- 바뀐 나라:
- 이 국경이 유지된 기간: 시작 ~ 다음 변화 전
- 경계 설명:               (현대 지명·강 이름 기준. 예: 북쪽 경계는 대동강 ~ 원산만)
- 확실성: 확실 / 추정 / 논쟁
- 출처:                    (지도가 실린 책·도록이면 쪽수까지)
- 참고 지도 이미지:          (있으면 파일로 첨부)
```

QGIS로 직접 그리셨다면 `.geojson` 파일만 주시면 됩니다.

## 4. 결정이 필요한 것

조사하면서 아래를 정해 주시면 데이터 구조에 맞게 옮기겠습니다.

> **2026-09-26 1차 입력(교과서 수준)에서 적용한 기본값**: 탐라는 표시하지 않음 · 후고구려는 한 나라(마진·태봉은 설명에 기재) · 말갈은 따로 표시하지 않음 · 웅진도독부·안동도호부는 당 영토로 칠함 · 676년 이후도 "신라"로 이어서 표시. 바꾸려면 알려 주세요.

- [ ] **탐라**: 독립 나라로 표시 / 백제·신라의 속국(종속 관계)으로 표시
- [ ] **후고구려·마진·태봉**: 한 나라로 두고 이름만 바꿈 / 국호마다 따로
- [ ] **말갈**: 독립 세력으로 영토 표시 / 발해 영토에 포함
- [ ] **웅진도독부·안동도호부**: 당 영토로 칠함 / 당이 점령한 지역(점령 관계, 빗금)으로 표시
- [ ] **통일 신라와 신라**: 한 나라로 이어서 표시(지금 방식) / 676년부터 이름을 "통일 신라"로 바꿔 표시
