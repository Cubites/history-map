## 2. 한 권역을 넣는 순서

1. **범위와 깊이 기준을 먼저 정한다** (5절). 다룰 시대, 나라 목록, 사건 수준을 정해 두어야 분량과 검수 기준이 흔들리지 않는다.
2. **뼈대부터 만든다.** 여러 나라가 얽힌 권역은 나라별로 따로 하면 경계가 계속 어긋난다. 시대별 나라 목록(`data/entities/<권역>.yaml`)과 **조각 소유표**(기간마다 어느 조각이 어느 나라 것인지)를 권역 전체에 대해 한 번에 설계한다.
3. **권역을 등록한다.** `area-list.mjs`에 import와 `AREAS` 한 줄, 권역 파일에 `export const source`(근거 문구, 없으면 한국사 교과서 문구가 붙는다)와 `export const gapZones`(비어 있으면 안 되는 지역)를 둔다.
   - **권역 필터 대응표에 한 줄** (2026-10-05): `src/schema/regions.ts`의 `REGION_FILTER_OF`에 `'<권역>': '<필터 단위>',`를 더한다(예: 중동을 유럽 필터에 넣으려면 `'middle-east': 'europe',`). 빠뜨리면 `build:data`·`check:data`가 그 나라 파일을 대응표에 없다고 멈춘다. 권역 값은 YAML에 적지 않고 빌드가 파일 이름에서 정한다.
   - 그 권역의 사건·전쟁 파일에 새 앞머리를 쓰면(예: `me-01-….yaml`) 같은 파일의 `STORY_FILE_PREFIXES`에도 `['me-', 'middle-east']` 한 줄을 더한다. 빠뜨리면 빌드가 멈춘다: 사건 파일은 알려진 앞머리나 한국사 시대 파일(두 자리 수로 시작, `01-gojoseon.yaml` 등)이어야 하고, 전쟁 파일은 `<영문자>-<두 자리 수>-` 꼴인데 앞머리를 모르면 오류다. 그 밖의 전쟁 파일(`imjin-war.yaml` 등)은 한국사(`korea`)로 본다.
   - 화면에 새 필터 단추가 필요하면 `REGION_FILTERS`·`REGION_FILTER_INFO`(이름·짧은 이름·지도 범위)에 더한다(DESIGN.md §6.4.2).
4. **조각으로 나라를 만든다.** 나라 버전 = `F(그 나라 조각 id들)`에, 현대 행정구역이 역사 경계를 가로지르는 곳은 이름 붙은 선 하나로 조각을 쪼개(`D(조각, 선)`·`I(조각, 선)`) 더하거나 뺀다. 같은 선을 쓰므로 틈이 생기지 않는다.
   - 한 조각을 같은 기간에 두 나라가 가지면 안 된다. '나머지를 갖는' 나라(오스만·러시아 등)는 조각 id 집합의 차로 만든다.
   - 유럽에서는 다각형을 빼서 만드는 채우기(`fillSpecs`)를 쓰지 않는 것을 권한다. 조각 집합 계산이 빠르고 정확하다.
   - 2026-10-02(작업 E2): 1815~1914년은 `europe.mjs`의 '1815~1914 조각 소유표'가 한곳에서 정한다. `whole(id…)`(통째 조각)·`split(이름, ids, [[부분, 도형]…], 나머지)`(차례로 자른 조각)로 단위를 만들고 `own(단위들, [[해, 나라|null]…])`로 주인을 적으면, 해마다 같은 단위 목록이 이어지는 기간이 그 나라의 버전이 된다. 조각을 두 번 쓰거나 빠뜨리거나 주인을 두 번 적으면 멈춘다. 다른 구간(1789~1815, 1914~)도 같은 표를 넓혀 쓰는 것을 권한다. 2026-10-02(작업 E3): 소유표를 시대마다 하나씩 두는 구조(`makeTable(첫 해, 끝 해)`)로 넓혀 '1789~1814 조각 소유표'를 더했다. 다른 표에서 나눈 조각은 `reuse(나눈 조각)`로 같은 단위를 쓰고, 이웃한 두 표에서 단위 목록이 같은 나라는 한 버전으로 이어진다. 2026-10-03(작업 B1): '1918~1945 조각 소유표'를 더하고 E2 표를 1917년까지로 늘렸다. 해마다 바뀌는 전선(독소 전쟁)은 전선 링 여러 개의 조합마다 단위를 만드는 도우미(`front`)로 나누고, 표가 바뀌며 단위 이름만 바뀐 이음매는 `SAME_LAND_SEAMS`로 잇는다. 2026-10-03(작업 B2): '1946~1991 조각 소유표'를 더했다. 앞 표의 블록 안에서 나눈 조각은 `B1_UNITS`로 꺼내 `reuse`하면 단위 목록이 같아 앞 버전이 그대로 이어진다. 2026-10-04(작업 A): '1992~현재 조각 소유표'를 더해 표가 지금(`PRESENT`)까지 이어진다. 마지막 표 끝까지 이어지는 버전은 `to: null`이다(`TAIL_TO` 없앰). 분쟁·실효 지배 지역은 법적 주인 색의 지역 항목으로 떼고 귀속 논쟁(`claimed_by`)·점령(`occupied_by`)·관계 없음 가운데 하나로 둔다(기준은 그 표의 머리 주석). 2026-10-06(작업 D1): '1700~1788 조각 소유표'(T1700)를 더해 표가 1700년부터 이어진다(계획은 `docs/EUROPE_DRAFT.md` 7절). 앞 표(1789~1814)에서 나눈 조각은 `E3_UNITS`로 꺼내 `reuse`한다. 앞 표와 다르게 나눈 조각을 써서 땅은 같은데 단위 이름이 달라지는 나라는 `LATER_LIST_SEAMS`(뒤 버전의 단위 목록으로 잇는 이음매)에 그 해를 적어, 뒤 표의 도형을 바이트 단위로 그대로 두고 버전의 `from`만 앞당긴다(넣기 전에 이음매를 빼고 만든 두 버전의 대칭차가 0인지 확인). 같은 날(작업 D2): '1600~1699 조각 소유표'(T1600)를 더해 표가 1600년부터 이어진다. 앞 표(1700~1788)의 블록 안에서 나눈 조각은 `D1_UNITS`로 꺼내 `reuse`하고, 표가 바뀌는 1700년에 단위 이름만 달라지는 나라(폴란드-리투아니아·베네치아)는 `LATER_LIST_SEAMS`에 1700년을 적었다. 권역 바깥선 밖 손 도형을 시기마다 다르게 그려야 하면(러시아의 시베리아 진출) 손 도형을 그대로 두고 그 해까지의 구역(`SIBERIA_ZONES`, [해, 링들])의 합집합으로 잘라 쓴다. 동아시아 쪽 도형을 건드리지 않고 경계가 늘 같은 손 도형 안에 머문다. 같은 날(작업 D3): '1526~1599 조각 소유표'(T1526)를 더해 표가 1526년부터 이어진다. 새 선은 긋지 않고 통째 조각과 앞 표들의 나눈 조각(`D2_UNITS`·`D1_UNITS`·`E3_UNITS`)만 써서 1599년과 1600년에 땅이 '1453~1525 조각 소유표'(T1453)를 더해 표가 1453년부터 이어진다. 새 선(가자리아·헤움노 땅·우그라강·트베리주 넷·우스튜그·비테그라·페초라·오버라우지츠 서쪽 끝·프스코프주 동쪽 끝)은 이 표에서만 쓰고, 그 선으로 나눈 조각을 쓰는 나라 가운데 1525년과 1526년의 땅이 같은 것(모스크바 대공국·폴란드 왕국·리투아니아 대공국·크림 써서 1299년과 1300년의 땅이 같은 나라는 1300년 버전이 앞으로 이어진다(카스티야만 1300년 이음매, 대칭차 0.0032km²). 정할 점의 기본값은 표 앞의 `M3_OPT`. 같은 날(작업 M2, 중세 2단계): '1300~1399 조각 소유표'(T1300)를 더해 표가 1300년부터 이어진다. 1400년 표의 블록 안에서 나눈 조각은 5. **권역 접합부를 맞춘다.** 러시아·소련의 손 도형, 카자흐스탄 쪽 `CENTRAL_ASIA`, 캅카스 쪽 `CAUCASUS_S`가 유럽 조각과 만난다. 러시아 = `D(손 도형, domain) ∪ F(러시아 조각)`처럼 두 경계가 한 자료에서 나오게 한다. 동아시아에서 50m 자료로 뽑은 선과 10m 조각 선을 한 경계에 섞지 않는다. 나라 id 하나는 한 권역에만 둔다.
   - 2026-10-01(작업 E1)에 했다: `france`·`uk`·`russia`·`soviet-union`·`russia-fed`를 `west`에서 `europe`(`scripts/geo/areas/europe.mjs`·`data/entities/europe.yaml`)으로 옮겼다(`west`에는 `usa`만 남음). 손 도형과 조각이 한 파일에 있어 `domain`은 `shared`로 내리지 않았다. 권역 바깥선 밖은 손 도형 그대로이고(동아시아 쪽 대칭차 0), 접합부 두 곳만 고쳤다: 아라스강 남쪽 이란 땅(약 1.2만km², 러시아·소련)을 상자로 빼고, 러시아 연방의 카자흐스탄 경계를 카스피해~오렌부르크는 `domain`이, 그 동쪽 동경 65.7°까지는 Natural Earth 50m 국경이 정하게 했다(카자흐스탄 땅 약 6.4만km²가 빠짐).
6. **검사한다.** 빈 땅 검사 구역(`gapZones`)에 `from`·`to`를 주면 그 해에만 검사한다(유럽은 1400년부터 지금까지(2026-10-04 작업 A에서 지금까지, 2026-10-06 작업 D1에서 1700년부터, 같은 날 작업 D2에서 1600년부터, 같은 날 작업 D3에서 1526년부터, 같은 날 작업 D4에서 1453년부터, 2026-10-07 작업 M1에서 1400년부터, 같은 날 작업 M2에서 1300년부터, 같은 날 작업 M3에서 1200년부터. 마지막 구역은 `to: null`), 소유표의 주인 없는 땅을 뺀 구역이 기간마다 하나씩). 시작 해는 가장 이른 소유표의 첫 해라 표를 더하면 따라 넓어진다.
   1. `npm run gen:geo` 뒤 `git status data/geo`: 기존 파일은 그대로이고 새 파일만 늘어야 한다. 바뀌었으면 `npm run compare:geo`로 기간마다 대칭차 면적이 0인지 본다.
   2. `npm run check:generator`(약 20초, 2026-10-02 작업 E3 뒤 약 2분 30초, 2026-10-03 작업 B1 뒤 약 3분 30초, 작업 B2 뒤 약 4분 15초. `gen:geo`도 약 20초 → 약 55초 → 약 90초(B2 뒤 약 85초), `check:gaps` 약 4분 30초. 같은 날 연산 메모·계산 캐시와 병렬 처리(DESIGN.md §5.2·§5.3)를 넣은 뒤로는 캐시가 없으면 `gen:geo` 약 27초·`build:data` 약 85초·`check:gaps` 약 65초, `gen:geo` 뒤 `check:generator` 약 18초이고, 캐시가 있으면 고친 나라에 걸린 계산만 다시 한다. `check:gaps`는 2026-10-05부터 캐시 없이 약 61초, 바뀐 것이 없으면 약 5초, 6절 참고) → `npm run check:data` → `npm run check:gaps` → `npm run check:exclaves` → `npm run build`

## 3. 유럽 조각에서 알아 둘 점 (작업 5에서 찾음)

- **근사다.** 현대 행정구역은 역사 경계가 아니다(예: 1970년대 독일 크라이스 개편). 권역 `source`에 근사라고 밝히고, 사료와 다른 곳은 조각을 쪼갠다. 1800년 이후 서·중유럽에서 효과가 크고, 중세·근세에는 선을 더 그어야 하는 곳이 많다.
- **조각이 거친 나라** (선을 더 그어야 함): 독일 16주(19세기 나라·프로이센 주와 안 맞음), 폴란드 16주(분할 경계), 벨라루스 7주(1921~1939 폴란드·소련 경계), 우크라이나 25, 러시아 58개 주체(1940년 카렐리야·비보르크 할양선), 체코 14(보헤미아·모라비아), 덴마크 5(북슐레스비히 1864·1920), 그리스 13(마케도니아·트라키아), 프랑스 06(1860년 전 니스 백작령). 잘게 나뉜 나라: 영국 231, 슬로베니아 193, 라트비아 119, 이탈리아 110, 프랑스 96.
- **분쟁·특수 지역**
  - 크림(UA-43)·세바스토폴(UA-40): 원본에서 러시아 소속이다. 1954~2014년 우크라이나 SSR·우크라이나 버전에는 이 두 조각을 우크라이나 쪽에 넣어야 한다.
  - 코소보: 30개 구(id `KOS-…`), 세르비아 25개와 따로 있다. 북키프로스는 조각 하나(CYN), 영국 주권 기지 아크로티리(WSB)·데켈리아(ESB)는 따로 있다(1960년부터 영국).
  - 소국: 안도라·리히텐슈타인·산마리노는 행정구역 단위, 모나코·바티칸·지브롤터는 한 조각씩. 바티칸은 로마(IT-RM)에서 따로 그어야 하고, 지브롤터는 50m 육지에 없어 자르면 사라진다.
  - 올란드 바깥 섬 7곳과 실리 제도는 50m·110m 육지에 없어 빠졌다.
- **저배율(110m) 해안**: 큰 해안 조각을 가까운 조각끼리 나눠 붙였기 때문에 갯벌·다도해 쪽 경계가 계단 모양이다(예: 바덴해).

## 4. 라이선스 규칙

- **Natural Earth**(퍼블릭 도메인): 가공한 조각 파일을 저장소(`data/base/fragments/`)에 넣어도 된다. 표기 의무는 없지만 README에 적었다.
- **CShapes 2.0**(CC BY-NC-SA 4.0): **좌표를 저장소에 넣지 않는다.** `.cache/`에 두고 `compare:cshapes` 대조로만 쓴다. 꼭 들여와야 하면 `data/third-party/cshapes/`에 파일과 NOTICE를 두고, 그 도형의 `source`·README·화면에 표기하며, DESIGN §12 표에 '나중 재라이선스에서 제외'를 적는다(`scripts/`의 MIT 파일에는 넣을 수 없다). 권하지 않는다. CShapes-Europe는 라이선스가 명시되지 않아 확인 전에는 쓰지 않는다.
- **OpenHistoricalMap**(기본 CC0): 필요한 선만 관계 단위로 받고, way마다 `source`·`license` 태그로 거른다. OSM에서 들여온 way와 `natural=coastline`은 뺀다.
- **쓰지 않는 자료**: Eurostat NUTS(재배포 불가), geoBoundaries(나라마다 ODbL·BY-SA가 섞임), GADM(재배포 금지), aourednik/historical-basemaps(GPL), Euratlas·GeaCron·Centennia(상용), HGIS Germany(학술 전용).

## 7. 이어서 작업할 때

1. `git pull` 뒤 `npm run check:generator`로 생성기 상태를 확인한다(전체 통과여야 함).
2. `.cache/`에 원본이 없으면 허락을 받고 받는다.
   - Natural Earth 1:10m admin-1 v5.1.2: `https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_admin_1_states_provinces.geojson`, 40,726,851바이트, git blob SHA-1 `4a8438f98ac7dfec7dc1739b1eaf91398ad33f22` → `.cache/natural-earth/v5.1.2/`
   - CShapes 2.0(대조용, 선택): `https://icr.ethz.ch/data/cshapes/CShapes-2.0.geojson`, 26,344,671바이트 → `.cache/cshapes/`
   - 조각 파일은 저장소에 있으므로 원본은 조각을 다시 만들 때만 필요하다(`npm run prep:fragments -- <원본 경로>`, 같은 입력이면 같은 바이트).
3. 다음 할 일 순서: ① 지도 파일 크기 대책 결정(6절) → ② 유럽 범위·깊이 기준 확정(5절) → ③ 유럽 권역 뼈대(시대별 나라 목록·조각 소유표) → ④ 접합부(러시아) 정리 → ⑤ 나라별로 채우기.
